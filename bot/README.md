# 🤖 BOT-MARKETPLACE GLOBAL

Полноценный Telegram-бот магазин с системой оплаты 50/50.

## 📁 Структура файлов

```
bot/
├── main.py           # Запуск
├── config.py         # ⚠️ НАСТРОЙКИ (токен, карты)
├── database.py       # База данных SQLite
├── keyboards.py      # Кнопки
├── translations.py   # Переводы (50 языков)
├── utils.py          # Утилиты
├── requirements.txt  # Библиотеки
├── railway.toml      # Конфиг для Railway
├── Procfile          # Запуск для Railway

│   └── catalog.py    # 20 типов ботов
└── handlers/
    ├── start.py      # Старт, капча, меню
    ├── catalog.py    # Каталог и заказы
    ├── cart.py       # Корзина
    ├── payment.py    # Платежи
    ├── casino.py     # Казино
    ├── support.py    # Поддержка
    └── admin.py      # Панель админа
```

## 🚀 ШАГ 1 — Получи токен бота

1. Открой Telegram, найди **@BotFather**
2. Напиши `/newbot`
3. Придумай имя и username для бота
4. Скопируй токен вида `7123456789:AAF...`

---

## 🌐 ШАГ 2 — Регистрация на Railway (БЕСПЛАТНО, без карты)

1. Зайди на **https://railway.app**
2. Нажми **"Start a New Project"**
3. Войди через **GitHub** (если нет — зарегистрируйся на github.com, тоже бесплатно)
4. Railway даёт **$5 в месяц** бесплатно — этого хватает на лёгкий бот!

---

## 📤 ШАГ 3 — Загрузи файлы

### Вариант A: через GitHub (рекомендую)
1. Зарегистрируйся на **github.com**
2. Создай новый репозиторий (кнопка "New repository")
3. Загрузи все файлы из папки `bot/`
4. В Railway: "New Project" → "Deploy from GitHub repo" → выбери свой репо

### Вариант B: напрямую
1. В Railway создай пустой проект
2. Загрузи файлы через интерфейс

---

## ⚙️ ШАГ 4 — Настройки (ОБЯЗАТЕЛЬНО!)

В Railway зайди в свой проект → вкладка **"Variables"** → добавь:

| Переменная | Значение |
|-----------|---------|
| `BOT_TOKEN` | `7123456789:AAF...` (твой токен) |

### Также открой файл `config.py` и замени:
```python
PAYMENT_CARD_UAH = "4441 1111 2222 3333"  # Твоя карта
REVIEWS_CHANNEL = "https://t.me/твой_канал"  # Ссылка на канал
```

## ▶️ ШАГ 5 — Запуск

После загрузки Railway автоматически запустит бота!

Зайди в Telegram → найди своего бота → напиши `/start`

## 💰 Как работает система оплаты

```
Клиент выбирает бот → Пишет ТЗ → Выбирает валюту
        ↓
Получает сумму с уникальными копейками (напр. 1750.37 UAH)
        ↓
Нажимает "Я оплатил" → Тебе приходит уведомление
        ↓
Ты нажимаешь "✅ Подтвердить" → Клиент видит подтверждение
        ↓
Делаешь бота → Нажимаешь /admin → "Уведомить о готовности"
        ↓
Клиент оплачивает вторые 50% → Ты подтверждаешь → Вводишь ссылку на архив
        ↓
Клиент получает ссылку! ✅
```

## ❓ Частые вопросы

**Бот не запускается?**
- Проверь, что BOT_TOKEN правильно добавлен в Variables

**Не получаю уведомления?**
- Убедись, что написал `/start` боту @BotFather от имени своего аккаунта
- Проверь ADMIN_IDS в config.py — там должен быть твой Telegram ID

**Как узнать свой Telegram ID?**
- Напиши боту @userinfobot

**Railway перестал работать?**
- Бесплатный лимит $5/мес. При превышении бот остановится до следующего месяца
- Это примерно 500+ часов работы — хватит надолго!
